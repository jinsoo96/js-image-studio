# series/ — 작품 폴더(레포에는 없음)

작품 내용(콘티·컷 설명·인물·대사·에셋·프롬프트·LoRA 설정·원작 원고·그린 컷)은 작업 PC 의 `D:\webtoon-studio\series\` 에만 둔다.
레포에는 만드는 법(도구·MCP·스킬·워크플로우)만 올린다(`.gitignore` 의 `series/*`).

- 작품 하나 = `series\<작품>-hf\` 폴더. 구성은 루트 `README.md` 의 "작품 폴더 구성" 절.
- 다른 PC 에서 이어 하려면 작업 PC 의 `series\` 를 따로 옮긴다(깃으로 받지 않는다).
- `_tmp\`(시험 결과물, `tools\clean_old.py` 가 10일 뒤 지움)·`_legacy\`(옛 판 글 자료)도 작업 PC 에만.
