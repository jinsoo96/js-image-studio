# 식자 · 출판

## 순서
1. 컷 놓기: `tools/hf_place.py <회차>`(panels_hf → panels, 폭 1600). 빼먹으면 예전 그림으로 합성된다.
2. 합성·PDF: `tools/run_episode.py <회차>`(합성 컷 → compose 말풍선 → 세로 조각 → PDF → 점검표). MCP `compose`.
3. 기계 점검: `tools/qa_gate.py`(막는 경고 0 이어야 넘긴다, 표지판식 자막 등) · `tools/check_bubbles.py`(말풍선이 얼굴을 가리는 컷 0).
4. 통독: 말풍선 얹은 조각(`out/slices`)을 처음부터 끝까지 본다.
5. 내보내기: `tools/trailer2.py` · `tools/to_epub.py` → `exports/<날짜>/`. MCP `export`.

## 식자 규칙(근거 LESSONS 7)
- 말풍선은 절대 얼굴을 가리지 않는다(이어 말하는 풍선의 띠도). 자리가 없으면 컷 위 여백에 꼬리를 단다.
- 풍선은 말하는 사람 쪽 절반·위쪽에. 어깨 너머 컷에서 앞사람 뒤통수 위에 놓지 않는다.
- 풍선 하나에 생각 하나, 컷 하나에 3개까지. 이어 말하는 풍선은 위→아래.
- 글자·말풍선은 그림 프롬프트에 넣지 않는다. 화면 속 글자는 상자.
- 작은 효과음 글자에 받침 ㅇ 이 든 글자는 피한다(흰 테두리가 구멍을 메운다).

## 막는 경고가 나오면
고친 뒤(자막은 콘티 파일, 그림은 그 컷만 다시) compose 를 다시 돌린다. 막는 경고가 0 이 아니면 내보내지 않는다.
