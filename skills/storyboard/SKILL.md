# 콘티

## 언제
사용자가 시나리오나 줄거리를 주고 한 화를 만들자고 할 때. 그림은 그리지 않는다(그리기는 `continuity`).

## 순서
1. 앞 회차 틀로 회차를 연다: MCP `new_episode(작품, epNNN)`(가장 최신 본보기 D+18 `ep002_v2`). Claude Code 는 앞 회차 `make_storyboard.py` 를 복사한다.
2. `make_storyboard.py` 를 이야기대로 새로 쓴다. 형식은 틀 그대로: `add(id, shot, scene, chars, *대사)` · `chat(id, 이름, 메시지)` · 제목 컷 · 작가 표기(`CREDIT`).
   길면 `start_file` → `append_file`(장면 단위, 4천 자 안팎) → `check_file`.
3. `prepare_episode` 로 storyboard.json 을 만들고 컷 수를 확인한다.
4. 사용자에게 컷 목록(번호·샷·장면·대사)을 보여 준다. "콘티까지"면 여기서 멈춘다.

## 규칙(근거 LESSONS 7·8·9)
- 한 컷에 행동 하나. 샷을 섞는다(넓은 컷 → 대화 → 클로즈업). 장면이 바뀌면 `scene` 도 바꾸고, 장소를 잇는 컷(들어서는 컷)을 넣는다.
- 대사는 짧고 살아 있게: 풍선 2~3줄, 인물마다 다른 말투, 바로 앞 대사를 받는다. 오글거리는 감정 직접 말하기·상투적 마무리 금지.
- 자막은 사람이 말하는 문장으로("그렇게 상병을 달았다."). 표지판식 명사구("다음 날 아침, 사무실.")는 기계 점검이 막는다.
- 그림을 설명하는 내레이션 금지. 생각 풍선엔 그 순간 떠올릴 말만.
- 이미 나온 설정(연대·호칭·직급·장소·옷)과 맞추고, 바꾼 곳은 사용자에게 알린다. 시간 자막은 바뀔 때만.
- 1화는 주인공의 화. 인물 소개 나열 금지, 첫머리 떡밥은 끝에서 회수.
